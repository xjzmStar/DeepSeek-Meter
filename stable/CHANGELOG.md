# 更新日志

## v2.2.3 (2026-10-01)
### 新增
- 峰谷计价改按**国家法定节假日**判定（DeepSeek 官方口径）
  - 法定节假日全天按低谷计费，峰谷标签显示节日名彩蛋（如「梁文谷·国庆节」「梁文谷·除夕」）
  - 节假日数据在线拉取（holiday-cn 主源 / jiejiariapi 备源），缓存到 `%APPDATA%\DeepSeek-Meter\holiday\{年}.json`，7 天内不重复拉取
  - 内置 2025/2026 兜底表，无网络也能正确判定；每年 11 月起自动预热下一年
  - 调休补班日均为周末，按官方口径仍计入低谷（无需单独维护调休表）
- 用户操作日志
  - 记录快捷键、托盘菜单、设置保存（字段级 diff）、窗口置顶、显示/隐藏、显示模式切换、窗口位置、余额查询失败、低余额提醒、检查更新、启动/退出等操作
  - 每天一个文件：`%APPDATA%\DeepSeek-Meter\logs\app-YYYY-MM-DD.log`，默认不自动删除
  - 设置面板新增「📂 打开日志文件夹」按钮
  - API Key 只记录「已更新/已清空」，绝不明文写入日志
### 变更
- 源码文件更名为 `stable/src/app_stable.py`（测试版对应文件为 `app/src/app_dev.py`），杜绝两条线同名混淆
- 新增配置项 `log_enabled`（默认开启）

## v3.0.0-snapshots-1 (2026-08-22)
### 变更
- 更新检查改为浏览器跳转 GitHub Release 页面下载（移除内置下载器）
  - 发现新版本后弹窗显示更新日志，确认后打开默认浏览器跳转 Release 页
  - 删除 `download_and_install`、进度条窗口、VBS 自动替换脚本
  - GitHub 下载速度远快于内置 urllib 下载
### 新增
- 挂件模式
  - 无标题栏、半透明显示（30%~100% 可调）
  - 四角定位（左上/右上/左下/右下）
  - 鼠标穿透（可选）
  - 双击挂件回到窗口模式
  - 挂件字体颜色自定义（时间/日期分别选色）
- 全局快捷键
  - `Ctrl+Alt+D` 显示/隐藏
  - `Ctrl+Alt+S` 打开设置
  - `Ctrl+Alt+M` 切换窗口/挂件模式
  - `Ctrl+Alt+Q` 退出程序
  - 快捷键可在设置面板自定义
- 窗口大小跟随字号自动缩放
- 多屏位置记忆（支持副屏坐标保存与恢复）
- 标题栏、托盘图标、任务管理器全部显示应用 logo
### 修复
- 修复 Windows Snap 吸附导致挂件拖拽到角落时自动变大卡死的问题
  - 进入挂件模式时通过注册表 `SnapAssist=0` 从系统级禁用 Snap 吸附
  - 退出挂件模式时自动恢复原设置
- 修复 VBS 启动器不等待旧进程退出就替换文件的问题
  - 改为循环检测旧进程退出（最多60秒）再执行替换
  - 增加 `os._exit(0)` 作为 fallback，确保旧进程一定退出
- 修复 Logo 在标题栏/托盘显示模糊或不显示的问题
  - 使用 PIL 精确缩放后转 tkinter PhotoImage，确保各尺寸清晰
